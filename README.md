# MJON Marketing Command Center

Panel de marketing digital local-first. Repositorio de desarrollo independiente de MJON TECH. La versión MVP incorpora clientes, pedidos, producción editorial por plantillas, revisión, aprobación y entrega simulada.

**Seguridad:** WhatsApp Business todavía no está conectado. Los datos se guardan localmente en IndexedDB; utilizar solamente datos de prueba antes de incorporar autenticación y un backend privado.

## Desarrollo

```sh
npm test
npm run check
npm run build
```
